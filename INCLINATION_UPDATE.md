# Обновление: ручной наклон

На экране «Данные» добавлены наклон, диапазон BLE, заданное значение и кнопки изменения на один шаг устройства. Используются 2ACC (поддержка), 2AD5 (диапазон) и opcode 03 через 2AD9. Фактическое значение берётся из 2ACD. При отсутствии свежей телеметрии кнопки недоступны. После команды ожидается ответ и достижение заданного показания, максимум 45 секунд.

Наклон выражен в процентах FTMS, а не в уровнях панели. Для первой проверки действует дополнительный предел 0–15%, также соблюдается диапазон устройства. Соответствие уровням панели 0–15 пока не подтверждено. Скорость и Stop используют прежние команды. Регулирование наклона автоматикой по пульсу не выполняется.

Установка: распакуйте архив обновления; загрузите папку app и этот файл в корень существующего GitHub-репозитория через Add file → Upload files. Сохраните Commit changes. Скачайте APK из нового успешного запуска Actions.

Проверка: закройте FitShow, подключитесь, проверьте отображаемый наклон и диапазон. Нажмите плюс один раз, дождитесь результата, сравните с панелью. Затем проверьте минус. При недоступных кнопках или ошибке скопируйте Debug-журнал. Проверку выполняйте с доступным физическим ключом безопасности.

Проверено: отдельная компиляция BLE-слоя Kotlin и 10 JUnit-тестов (телеметрия, диапазон, команды). Полная Compose/APK-сборка в этой среде не выполнена. Проверка реального привода наклона ещё необходима. Автокоррекция пульса, программы и история не завершены; это обновление добавляет ручной наклон.
